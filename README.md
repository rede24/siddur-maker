# Siddur Maker

תבנית ליצירת אפליקציית סידור חדשה על בסיס המבנה, העיצוב ומנוע ה־LEGO של
[`rede24/siddur`](https://github.com/rede24/siddur).

האפליקציה שנוצרת היא PWA עברית, RTL, אופליין, עם קורא דפים, זום, מחוות,
לוח עברי והרכבת תפילות מבלוקים לפי היום.

## שימוש

1. יוצרים Repository חדש מהתבנית.
2. מכניסים PDF אחד או יותר לתיקייה `source/`.
3. שולחים לסוכן:

   > קרא את AGENTS.md במלואו. בנה מה־PDF שבתיקיית source סידור חדש לפי
   > התהליך המוגדר, בדוק את סדר התפילות ופרסם את הקבצים בתוך public.
   > אל תבצע deployment.

4. הסוכן מחלץ את העמודים, מגדיר אבני LEGO, מתאים את המסכים והבדיקות ומכין
   את `public/` לפרסום.

## הרצה מקומית

```bash
npm install
npm run dev
```

פתחו `http://127.0.0.1:4173`.

## בדיקות

```bash
npm test
npm run test:browser
```

## חשוב

- אין בתבנית עמודי סידור מוגנים בזכויות יוצרים.
- אין Deployment אוטומטי ואין הגדרת Cloudflare.
- `public/` הוא התוצר המוכן לפרסום; בחירת שירות האחסון נעשית בנפרד.
- חובה להשתמש בעמודי מקור מלאים. אין לחתוך או לשכתב את נוסח התפילה.
