# אבני הבניין של הסידור

התפילה נבנית כעץ. רשימת עמודים שטוחה נוצרת רק כשהקורא מציג אותו.

1. **אבני בסיס**: עמוד תמונה מלא.
2. **מקבץ**: סדר של אבני בסיס, למשל ברכות השחר או הלל.
3. **מקבץ מורכב**: מקבצים בתוך מקבצים, למשל פתיחת שחרית או סדר יום שיש בו מוסף.
4. **תפילה יומית**: תבנית הבוחרת מקבצים לפי תאריך, תפילה ומיקום.

## דוגמה

```js
// עמוד בסיס מלא
page('79')
// מקבץ
group('song-fri', 'שיר של יום שישי', [ref('page:79')])
// מקבץ מורכב עם תנאי
group('song-of-day', 'מזמורי היום', [
  choose('h.weekday', {Fri: ref('song-fri')}),
  when('ledavid', ref('ledavid'))
])
// תפילה יומית
composePrayerTree('shacharit', planForPrayer(date, 'shacharit', location))
```

התבניות והקטלוג ניתנים לסריאליזציה ל־JSON. אין בהם פונקציות תנאי.
הפניה חסרה או מעגל הפניות גורמים לשגיאה מפורשת.
אפשר להשתמש באותו מקבץ בכמה תפילות ולקנן אותו לעומק נוסף.
שינוי של עץ יום אחד אינו משנה את הקטלוג או עץ אחר.

## הוספת קטע

מגדירים אבן בסיס עם עמוד מקור מלא בקטלוג, מוסיפים אותה למקבץ,
ומפנים למקבץ בתבנית. בחירה לפי היום משתמשת ב־when או choose.
טווחי העמודים נשארים בקטלוג; תבנית התפילה מכילה הפניות בלבד.

עמוד שמכיל סוף של קטע חובה נשאר תמיד בתוך אותו מקבץ, גם אם בהמשך אותו עמוד
מודפס קטע שאינו נאמר היום. שלמות התפילה קודמת להסתרת טקסט מיותר.

## גבולות התוכן הקיים

הרפקטור שומר על רצף העמודים הקיים. הוא אינו מאמת מחדש את נוסח התפילה.
דפי הנחיות אינם מוצגים ברצף התפילה. עמודי המקור המלאים וסדר הבחירה לפי היום נשמרים.
קריאת התורה, סליחות, מגילה וקינות אינן כלולות כאשר אין נכסי נוסח.
שבת ויום טוב עדיין אינם מכוסים. אפשר להשלים את הקטעים בקטלוג בלי לשנות את המנוע.
